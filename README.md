# tagmesh

Tag URLs and mesh query parts with stable normalization.

**Site:** https://theworker02.github.io/tagmesh/

## Install / run

```bash
git clone https://github.com/theworker02/tagmesh.git
cd tagmesh
node src/cli.js
node --test
```
